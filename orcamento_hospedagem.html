A equipe escolheu o GitHub Pages porque:

  • não tem custo, o que é adequado a um projeto acadêmico;
  • entrega HTTPS automático, exigido na entrega;
  • publica a cada commit, integrando deploy e versionamento;
  • atende bem um site estático e leve, com imagens em SVG e pouco consumo de dados, alinhado ao tema de sustentabilidade.

Se o projeto virar uma ONG real, o próximo passo seria registrar um .com.br no Registro.br e apontá-lo para o GitHub Pages ou para uma hospedagem paga.
